Privacy Policy

Last updated: October 21, 2026

This policy covers the First Try website and First Try Uploader, a private tool the First Try channel uses to publish its own videos to its own YouTube channel.

Who uses First Try Uploader

First Try Uploader is used only by the owner of the First Try YouTube channel (@firsttryvids). It is not offered to the public, and no one else signs in to it.

What data it accesses

  • YouTube upload permission (youtube.upload) — to upload First Try's own videos to the First Try channel.
  • Read-only YouTube access (youtube.readonly) — to read public comments on First Try's own videos so it can count audience votes (for example "A" or "B") that decide the next episode.

Comment text is processed only to count votes. It is not stored beyond vote totals, and no profile information about commenters is collected or kept.

How data is stored and shared

Sign-in tokens are stored encrypted and used only to perform the actions above. First Try does not sell, rent or share any data obtained through Google APIs with anyone, does not use it for advertising, and does not use it to train AI models. First Try Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

This website

This website does not use cookies, analytics or trackers, and does not collect personal information.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
